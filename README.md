# Arthur Delhaye — Research Portfolio

A minimal, single-page research portfolio. No framework, build step, or npm installation.

## Preview the site

1. Extract the entire ZIP.
2. Open `index.html` in Chrome or Edge (or run `start index.html` in the Windows terminal).
3. Keep `styles.css`, `assets/`, and `Arthur_Delhaye_CV.pdf` alongside `index.html`.

## Publish with GitHub Pages

1. Create a public GitHub repository named `<YOUR-GITHUB-USERNAME>.github.io`.
2. Upload **the contents of this folder**, not the enclosing folder, to the repository root.
3. Go to repository **Settings > Pages**.
4. Select **Deploy from a branch**, then choose `main` and `/ (root)`.
5. Your site will appear at `https://<YOUR-GITHUB-USERNAME>.github.io/` once GitHub completes deployment.

## Updating content

- Edit the words and external links directly in `index.html`.
- Adjust layout and colors in `styles.css`.
- Replace images under `assets/` using the same filenames.
- The included `Arthur_Delhaye_CV.pdf` is the previously prepared public CV version with the phone number omitted; verify it is current before publishing.
- The portfolio uses the real photos provided by Arthur and a chart excerpt from the UQAR Deep Sleep Optimizer report.
- Sleep2Word links to the arXiv v1 preprint (arXiv:2611.21643). Its status is **preprint**, not an accepted conference paper.

No npm commands are needed.
